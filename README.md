# 物理の世界と先端技術 小テスト対策アプリ

「物理の世界と先端技術」（第1回〜第3回：ニュートン力学、対称性、保存則）の講義内課題および小テスト対策のためのインタラクティブWebアプリケーションです。

## 主な機能
- **講義内課題 完全制覇**: 第1回〜第3回の最終スライド課題（穴埋め＋記述）を本番形式で演習
- **回別 予想問題演習**: 講義スライドの重要論点に基づいた穴埋め・文章作成予想問題
- **スマート自動採点**: 記述問題において必須キーワードの網羅性だけでなく、物理学的な因果関係・論理条件を判定
- **総合模擬小テスト**: 制限時間15分のタイムアタック模試（穴埋め3問＋記述2問）
- **重要語句マスターカード**: スライド内の色付き重要語句（全22語）の解説・暗記カード
